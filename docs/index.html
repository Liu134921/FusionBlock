把广告拦干净，不误伤微信。

四份 AdGuard 过滤器，合并六个上游源。去重、化简、把会误伤常用服务的规则挑出来单独处理，再用四十二个关键域名过一遍体检。订阅之后，它每八小时自己更新。

安装 Gitee 仓库

适用于 AdGuard for Android、Windows、Mac 和 AdGuard Home；浏览器扩展版也能用，但没有 App 拦截得干净。

AdGuard → 设置 → 过滤器 → 自定义过滤器 → 按 URL 添加。四份都加上，白名单别漏。每张卡下面两个按钮，一个是直接拉起 AdGuard，一个是复制地址。

「添加到 AdGuard」用的是 AdGuard 自己的订阅接口，只有手机上装了 AdGuard 才有反应；电脑上点它没动静是正常的，用「复制链接」。这四份是 AdGuard 语法：||域名^ 拦截、@@ 例外、## 元素隐藏。Clash、Surge、hosts 这些工具不认，导进去没有效果。国内直连 GitHub 通常拉不动，所以地址给的是 Gitee 镜像；Gitee 每八小时从 GitHub 同步一次，最多晚八小时。

增强脚本

过滤器管得到请求，管不到页面里发生的事：遮罩、弹窗、自己跳走的链接。这几件交给一个用户脚本。

  • 拆掉遮罩「检测到你使用了广告拦截」的浮层，连同被锁住的页面滚动一起解开。
  • 拦住弹窗没有你的操作却自己打开的窗口、跨域自动跳转，一律拦下。
  • 换回原文搜索结果里的 AMP 页面，在点开之前就换成原地址。
  • 清掉横幅Cookie 同意条，和钉在页面底部的广告条。

浏览器打开

关于

这事起于一张没收到的微信图片。查到是列表里的一条规则把 wxs.qq.com 整个拦了——图片、头像、表情全走这个域，换一份列表也躲不掉，几个源里都有。

当时手机上叠了十一个列表、一百三十五万条规则，四成是重复的。现在这四份是重新合成的：先是自己用，顺手放出来。
